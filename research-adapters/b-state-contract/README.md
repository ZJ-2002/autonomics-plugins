# B state normalization candidate sources

`scripts/run-tpm.py` is generated by
`scripts/build_b_state_expression_wrapper.py` and embeds the complete stdlib
normalization implementation and its raw-count validators. Regenerate after
changing either source; `--check` rejects stale bytes.

The fixed entry uses 11 input and 5 output environment ports. For the exact
source/recipe contract and remaining scientific/runtime gates, see
`docs/research-execution/B_STATE_NORMALIZATION.md`.

The candidate manifest registers three fixed Python preparations in the
content-pinned private Python image: donor TPM (11/5 ports), score inputs
(12/4), and contrast inputs (14/4). It does not register a general script tool.
The two fixed R entries have a separate `b-state-method` manifest and image;
their canonical sources remain here and the generators mirror identical bytes.
Neither manifest grants G0, scientific acceptance or full protected-pipeline
qualification. Production registration is unchanged.

Core B program scoring adds generated `run-score-inputs.py` (12/4 ports) and
`run-score.R` (6/5 ports), built by `scripts/build_b_state_score_wrappers.py`.
The source R method invokes official singscore and consumes the actual
source-bound preparation receipt. See `docs/research-execution/B_STATE_SCORING.md`
for member/orthology/background, explicit coverage, viewing-history preservation
and remaining full-family/server/image gates. Both manifests remain undeployed
production candidates; this does not make B-SPEC or the complete scheme ready.

Core B score contrasts add fixed `run-contrast-inputs.py` (14/4 ports) and
`run-contrast.R` (6/4 ports), generated by
`scripts/build_b_state_contrast_wrappers.py`. They consume actual count,
normalization and hash-on-write scoring receipts plus original metadata and
complete frozen sample/analysis decisions. They invoke only explicitly selected
Welch or paired t models; no default replaces another core B method or B-SPEC.
The R candidate has actual private-container component evidence, separately
from full-family/protected-worker admission and real scientific qualification. See
`docs/research-execution/B_STATE_CONTRASTS.md` for full-family/server/image gates.
