# Official MICE technical adapters

Pinned local proof image: official CRAN mice 3.19.0 source archive, unmodified,
compiled with R 4.6.1. This is not a production installation or complete MICE
API/domain certification. Actual-DAG and independent-source reference proofs
must complete before any acceptance verdict.

`cachexia_mice` takes raw typed lexical TSV, frozen JSON, and a complete
cell-level missingness/eligibility receipt. Methods, predictor matrix, visit,
where/ignore masks, finite integer seed and RNG kinds are explicit. Numeric
binary data are not silently reclassified by the number of unique values.
Death/structural cells cannot be imputed or used to fit the imputation model.
No silent predictor removal, inferred method, custom/passive code or parallel
RNG is allowed in this technical route. Logged events and requested cells
remaining missing block execution; absence of events does not prove convergence
or MAR/MNAR assumptions.

`cachexia_mice_complete` takes the complete official mids bundle, frozen JSON,
and the same missingness receipt, not a table called a mids object. Official
numeric actions and all/long/broad/repeated/stacked, include/mild/order semantics
are preserved in full RDS. `action=all` returns a mild list, not a long table.
The mechanical binder replaces only a root unresolved upstream SHA256 token;
all other JSON bytes, including floating-point tokens, remain unchanged.

The PMM/logreg nodes take raw typed TSV, frozen observed/requested masks and
method parameters, and the same missingness receipt. They return official
draws with exact original row identities, not anonymous numeric positions.

Analysis ports: values TSV, full state RDS, audit JSON, log, complete original
missingness ledger, and diagnostics TSV. Factor values carry integer level
codes plus separate exact labels; these codes are not clinical numeric effects.
MISSING remains missing/typed NULL. Complete original identities and masks
remain in RDS, including protected or unrequested missing values.

This does not pool imputed data or justify a longitudinal analysis, study
enablement, real death/selection handling, portability, full-scale resources,
persistent/resident deployment, forged-RDS security or G0.
