# Full-precision original LDSC results

This opt-in family reuses the already acquired pristine CBIIT LDSC
`6c673952cee74bd5c57aef1555a03b1c015399a0` implementation in immutable image
`ghcr.io/zj-2002/ldsc@sha256:e98d2a89b0412384bbec1369250d935868a919f8a164c4ce55b282ac13495767`.
This is the anonymously accessible public publication of the earlier localhost
digest, retaining the exact image configuration and all measured author
runtime/package identities. OCI manifest digests differ; they are not relabeled
as the same digest. A successful pull is not an installed profile, numerical
requalification, actual LD-panel qualification or scientific certificate.
No statistical method is reimplemented or repaired by this wrapper.

- `ldsc_h2_frozen_precision`: config, munged sumstats, complete panel manifest.
- `ldsc_rg_frozen_precision`: config, ordered two munged sumstats, panel manifest.
- Both publish five ports: result JSON, original log, content-bound audit,
  exact bound config and every field of the official returned object.

Configuration must declare v4.3.2/A_ARCH, original archive identity, explicit
analysis/phenotype IDs, input evidence identity, unconstrained intercepts,
jackknife blocks, outlier cutoff/default, seed, paired prevalence/observed
scale, exact Python/package/source identity and actual input digests. Native
`frozen_config_inputs` can bind the reserved input hashes from actual producers.
`FROZEN` freezes numeric recipe bytes; it does not approve a module or family.

Every source, runtime and all declared panel files are reverified after
computation. All22 chromosomes of reference LD scores, reference M_5_50 and
weights are mandatory. Gzip detection uses bytes, not a filename suffix.
The full unique munged SNP row census is retained in receipts. Full-precision
P comes from the returned RG object, never a rounded display log. The explicit
validity policy follows the default official summary: nonpositive h2, missing
results and rg outside [-1.2,1.2] remain NOT_ESTIMABLE for family P; the complete
raw official object/values remain retained. Negative h2 diagnostics are retained
and receive no invented inferential P or multiplicity family. Scientific review
must independently accept this policy and the actual source/scale/overlap.

Pristine upstream's invalid-allele component bug is preserved as a visible
failed method. A swallowed pair exception cannot become a fallback estimate.
Nonfinite returned state is tagged with its original missing reason, never
replaced with zero. Inputs exceeding complete-state budgets fail explicitly.

## Measured technical scope

Five actual pinned-container cases cover h2/rg observed and liability
configurations, gzip without an extension and nonpositive-h2 missingness.
Every returned field is compared to an independent direct invocation of the
same pristine official API: 2,235 fields including 1,693 finite numeric fields
match exactly. Four further actual container cases refuse a changed input
hash, incomplete chromosome22 panel, changed runtime identity and duplicate
config keys, with no normal numeric/state/config outputs published.
Nine offline contract tests are required by catalog CI.

```sh
python -B plugins/ldsc-precision/tests/run_precision_container_assurance.py \
  --output /absolute/new-private-evidence \
  --runtime /absolute/independently-recorded-runtime.json
```

The test runner reuses the default existing Podman store unless an explicit
shared store is supplied. Any temporary native store for that optional mode
stays in managed TMPDIR, never inside permanent method evidence.

All method evidence is synthetic GWAS and synthetic22-chromosome panels. It
proves scoped transport/full-object parity, not actual reference-panel
qualification, an entire88-pair A_ARCH run, same-run native lineage, family
correction/sealing, G0 or scientific/formal authorization. Production engine
admission and result visibility must be independently enforced.
