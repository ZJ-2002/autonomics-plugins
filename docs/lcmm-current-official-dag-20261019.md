# LCMM: current official-adapter DAG evidence

## What is accepted

The three finite official alternatives are `cachexia_hlme`,
`cachexia_hlme_predict` and `cachexia_hlme_compare`, not an unconditional
qualification of the original numeric/native interfaces. The repaired wrapper
and the unchanged author image were exercised using the original frozen
technical inputs and independently compiled author-reference results.

| Alternative | Current scoped fixture | Numerical fields | Declared outputs |
| --- | --- | ---: | ---: |
| `cachexia_hlme` | Prespecified one-class Gaussian mixed-model fit | 6,277 finite | 6 |
| `cachexia_hlme_predict` | Complete frozen two-class fit; analytical mean bands | 7,524 finite | 6 |
| `cachexia_hlme_compare` | Two complete frozen fits on identical observations | 13,803 finite, 1 missing | 6 |

All 27,604 finite fields have zero observed difference from the frozen reference;
the tolerance remains `atol=1e-12, rtol=1e-12`. Three complete RDS comparisons
also passed, retaining covariance, posteriors, predictions, original lexical
axes, frozen requests, lineage and RNG. Only the same author call/formula
representation and elapsed-runtime exclusions used in the original reference
protocol were applied. Original row ledgers and subject maps match byte for byte.

Two actual failed graphs verify a mismatched input hash and a foreign output.
Both produce zero analytical ports and skip both downstream consumers. Existing
foreign content survives. Hash-only binder nodes were actually exercised in the
prediction and comparison graphs; they do not edit scientific settings.

## A real integration counterexample and its correction

The first batch's fit and prediction graphs completed successfully. Its
comparison method also completed, but a direct TSV-to-DataFrame edge failed
while parsing the legitimate missing token `NA` as `Float64`. The batch remains
failed; it is not relabelled successful.

The corrected comparison graph uses the existing explicit-schema
`cachexia_lcmm_values_to_parquet` bridge before the native Parquet reader and
materializer. All 13,804 rows, the missing value, lexical coordinates and unique
source positions are retained. Neither deleting the missing row nor changing the
generic TSV reader's missing-value policy is used as a workaround.

The two explicitly successful, source-identical component DAGs were reused from
the failed batch. Only comparison and the corrected boundary were repeated; no
model fitting or prediction was repeated. A successful final managed run checked
all three complete RDS objects against the frozen independent references. Six
containers from that final run were observed stopped; the earlier batch's five
owned containers were separately observed stopped. The source identities,
component exits and hashes remain distinct from the failed batch exit.

The earlier 100-DAG method/contract reference packet remains intact, with 180
author namespace function comparisons. Its numerical branches are reused where
the method/helper ASTs and pinned image are unchanged; they are not described as
100 newly executed graphs. Failed discovery/relocation attempts are retained,
including the attempt that looked for pre-archive permanent paths. The repair
maps only a known session's permanent prefix to its sealed archive and still
requires identical file size and SHA256.

## What this does not grant

- No full author API, arbitrary input, original native optimizer/prediction/BIC
  weight implementation or current resident daemon qualification.
- No newly executed single combined refit-to-prediction-to-comparison pipeline;
  these are three explicit component DAGs with frozen qualified parent objects.
- No general hostile-workspace/race certification for the unchanged typed bridge;
  its current scope is the managed fresh owned output workspace.
- No portability claim for the local-only image, no production deployment and no
  permission to run actual study observations through a synthetic-only contract.
- No scientific class selection, trajectory/landmark eligibility, implementation
  lock, research sign-off or G0.

The historical host runtime lock is still not silently refreshed:
`/etc/ld.so.cache` differs, so the old host-profile route is not newly admitted.
The actual graphs use the unchanged content-addressed author container instead.
B-S remains `CONDITIONAL_NOT_READY`; GS01 remains `OPEN`; 276/288/696 are unchanged.
