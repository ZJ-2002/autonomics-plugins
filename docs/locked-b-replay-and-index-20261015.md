## Proof-checker defects fixed before the full run

- Repeated kinds must bind each published port to its actual execution run_name,
  not a glob that expects only one instance or chooses the first equal file.
- RDS comparison must check numeric leaves elementwise, with exact structure,
  attributes, types and NA/NaN/signed-Inf masks. Aggregate `all.equal` alone can
  hide a local error behind a much larger component. A non-fitting counterexample
  and positive/refusal controls run before fitting; frozen tolerances are not
  relaxed to make results pass.
- A method-refusal control requires its actual pinned image/digest, integer
  exit2 and specific method diagnostic. OOM, permission and launch failures are
  not evidence of a source/schema guard. Downstream nodes must actually be
  skipped with no execution or normal output, not merely unsuccessful.
- The runner and build record must be actual members of the same sealed archive.
  An unsealed file beneath a valid session ancestor, traversal alias or arbitrary
  same-hash external executable does not establish build provenance.
