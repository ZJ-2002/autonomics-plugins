## Reusable engineering probe, not an automatic scientific certificate

`official_plugin_dag` loads an explicitly named, hash-bound file-backed plugin.
It registers four I/O/SQL factories and the declared external plugin factories,
not native statistical factories. Declared panel replacements must be explicitly
technical/synthetic; strict manifest/object identities remain mandatory. Script
traversal and replacement of an engineering factory are refused.

Six actual initialization refusals cover wrong manifest hash, wrong plugin name,
native statistical node request, engineering-name collision, script traversal
and an inconsistent panel mapping. A separate **eight-node/seven-edge no-panel R
transport** case reproduces an already-qualified BH table byte-for-byte and checks
all five live/published ports. It grants no new R method certificate.

The generic name is a reuse mechanism, **not evidence that any supplied plugin is
official or scientifically approved**. Each method still requires its own source,
reference and interpretation proof. In particular, generic SQL query semantics
and all execution entrypoints have not been globally certified or made into a
non-bypassable scientific-admission system.
