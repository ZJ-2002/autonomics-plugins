## Method contract

`frozen_a_family_assemble` uses the frozen v4.3.2 `strict_conjunction` helper:
the path raw P is the maximum of both component primary P values, and remains
missing if either component is not estimable. The direct X-to-Y P, product P,
and another available edge cannot replace a missing component.

This is an explicit study-defined Python adapter, not an author Boolean-test
package. `frozen-a-family-adjustment` invokes official R `stats::p.adjust`.
Mapping missing raw P to one only for the complete adjustment vector is the
frozen study contract, not the default R NA policy. Raw missingness is retained.
