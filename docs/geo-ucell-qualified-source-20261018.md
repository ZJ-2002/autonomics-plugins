# Qualified GEO and UCell source repairs

This release publishes previously reviewed source fixes, not new statistical
implementations or a research authorization. It does not change production
configuration, frozen study files, or scientific eligibility.

## GEO transport

The six GEO files match the preserved reviewed candidate exactly. The repair
rejects malformed matrix/metadata contracts and protects foreign outputs.
The prior 38 offline regressions are reused; eight targeted integration checks
ran against the restored canonical files. No new data were downloaded.

The four affected fixed candidates are `geo_series_matrix`, `geo_soft`,
`geo_suppl`, and `sra_runinfo`. These are engineering transport nodes, not
implementations of a statistical package. Live endpoints, current native DAG
execution, and resident deployment are separate from this source repair.

## UCell wrappers

Both wrappers call official UCell 2.16.0; the repaired code handles output
ownership and failure diagnostics, without rewriting the scoring algorithm.

- H5AD: 46 actual isolated DAGs, 20 whole-object reference comparisons and
  148,165 finite values, seven direct controls and three construction controls.
  All 54 owned containers stopped.
- TSV: 13 actual isolated DAGs, 12 complete reference RDS comparisons and
  208 score values, 16 original direct boundaries and two construction controls.
  All 30 owned containers stopped. Existing author-reference objects were
  reused; no new oracle was created.

The TSV proof driver now invokes actual graph construction rather than treating
transport-only validation as a graph check. Its cached-image launcher observes
the SDK's `pull=missing` and changes only that policy to `never`; CPU, memory,
read-only root and network settings remain unchanged. Failed attempts remain
failed records, not reclassified as successes.

Source export checks cover only changed test modules and catalog/provenance
integrity. Their test counts are not node certificates. This release does not
certify all package APIs, full-scale resources, hostile concurrent mutation,
clean-install image availability, current resident execution, or G0.

B-S remains `CONDITIONAL_NOT_READY`; GS01 remains `OPEN`.
